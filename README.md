# CollectionReport

**Automated collection sales & inventory reports delivered to Slack on your schedule.**

![CollectionReport Screenshot](docs/screenshots/collection-report-preview.png)

## Features

- **Scheduled Reports** — Daily, weekly, or monthly collection performance reports sent automatically to Slack
- **Collection Picker** — Select any Shopify collection via the native Resource Picker
- **Rich Slack Messages** — Block Kit formatted reports with revenue, order counts, top products, and low-stock alerts
- **Flexible Scheduling** — Set delivery time, day of week/month, and optional start/end dates
- **Instant Preview** — Preview report output in Slack Block Kit format before enabling
- **Send Now** — Trigger any report on demand with a single click
- **Status Tracking** — Dashboard shows active, pending, expired, and disabled reports with delivery logs

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Remix (Shopify App Template) |
| Language | TypeScript |
| Database | Prisma + SQLite |
| UI | Polaris React |
| API | Shopify GraphQL Admin API |
| Notifications | Slack Incoming Webhooks |
| Scheduling | cron-job.org (external cron) |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- [Shopify CLI](https://shopify.dev/docs/apps/tools/cli)
- A Shopify development store
- A Slack workspace with an Incoming Webhook URL

### Setup

```bash
# Install dependencies
npm install

# Set up the database
npx prisma migrate dev

# Start development server
shopify app dev
```

### Deployment

```bash
shopify app deploy
```

## Architecture

```
collection-report/
├── app/
│   ├── routes/          # Remix routes (dashboard, report CRUD, cron endpoint)
│   ├── services/        # Server-side logic (report generation, Slack sender, scheduler)
│   └── components/      # Polaris React UI components
├── prisma/              # Database schema (ReportConfig, ReportLog)
└── shopify.app.toml     # Shopify app configuration
```

Reports are generated by querying the Shopify Admin API for order and inventory data scoped to a collection, then formatted as Slack Block Kit messages. An external cron service calls the `/api/cron` endpoint which evaluates each report's schedule and validity period before sending.
